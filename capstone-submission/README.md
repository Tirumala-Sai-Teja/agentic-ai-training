# Capstone Submissions

Place member submissions in the following structure:

```
capstone-submission/
├── CHN/                    # Chennai members
│   ├── MemberName1/
│   │   └── solution.ipynb  (or .py, or both)
│   └── MemberName2/
│       └── capstone.py
├── HYD/                    # Hyderabad members
│   └── MemberName3/
│       └── solution.ipynb
├── BLR/                    # Bangalore members
│   └── MemberName4/
│       ├── agent.py
│       └── utils.py
└── EVALUATION_REPORT.md    # Auto-generated by /evaluate-capstone
```

## Notes
- Each member gets their own folder named after them
- Supported file types: `.ipynb`, `.py`
- Non-standard directory structures within a member's folder are handled automatically
- Run `/evaluate-capstone` to evaluate all locations
- Run `/evaluate-capstone CHN` to evaluate only Chennai members
